# EspDesktop Homebrew tap

Install the [EspDesktop Mac app](https://jtenniswood.github.io/espdesktop/) on
an Apple silicon Mac running macOS 13 or newer.

```sh
brew install --cask jtenniswood/tap/espdesktop
```

To update through Homebrew, run `brew update` and then
`brew upgrade --cask jtenniswood/tap/espdesktop`. EspDesktop can also update
itself from the menu bar.

The [EspDesktop release workflow](https://github.com/jtenniswood/espdesktop/actions/workflows/homebrew.yml)
updates this cask when a stable Mac release is published. Use the
[Mac setup guide](https://jtenniswood.github.io/espdesktop/getting-started/mac-app)
to pair your display.
